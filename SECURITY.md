# Security Policy

## Supported Versions

We track security updates for the current major releases of our project. Please see the table below for supported version status:

| Version | Supported          |
| ------- | ------------------ |
| < 1.0   | :white_check_mark:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly. 

* **Where to report:** Send an email to the project maintainer at [your-email@example.com] or open a private security advisory on GitHub.
* **What to include:** Please provide a summary of the vulnerability, steps to reproduce the issue, and the potential impact.
* **Response timeline:** You can expect an initial acknowledgment of your report within **48 hours**, along with an estimated timeline for a fix if the vulnerability is accepted.
